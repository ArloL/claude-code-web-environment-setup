# Hosts that specific projects need, rather than anything this setup installs.
#
# These cannot be derived from any upstream list -- the source of truth is the
# project's own build file. When a new project needs a repository, the honest
# thing is to add it here with a pointer to the build file that declares it.

# Declared as a <repository> in the pom.xml of projects that consume snapshot
# builds straight from a git ref.
jitpack.io

# The published GitHub Pages site of ArloL/arlol.github.io. Reaching the
# deployed page needs the github.io host: github.com and
# raw.githubusercontent.com are in Anthropic's default list, but the host that
# serves the built site is not.
# Source of truth: https://github.com/ArloL/arlol.github.io
arlol.github.io

# zizmor's documentation site. Every zizmor finding is reported with a
# docs.zizmor.sh/audits/#<id> link and the audit rules only exist there, so
# fixing what the zizmor job reports means fetching that page.
# Source of truth: the `uvx zizmor` step in
# .github/workflows/check-actions.yaml, and https://github.com/zizmorcore/zizmor
docs.zizmor.sh

# Maven Central is NOT listed: repo.maven.apache.org and repo1.maven.org are in
